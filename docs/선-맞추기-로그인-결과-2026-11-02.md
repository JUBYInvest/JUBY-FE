# 나란한 열의 선 맞추기 · 로그인 화면 다시 디자인 (2026-11-02)

사용자 요청 두 가지:

1. 홈 '현재 주가 보기'와 '커뮤니티'의 굵은 먹 선이 어긋난 캡처를 보이며 "이렇게 묘하게 선의 위치가 맞지 않는 것들을 찾아서 다 정리해줘."
2. "로그인 페이지는 너무나 별론데, 이것을 최신 환경에 맞춰서 ui 스킬을 활용하여 아예 다시 디자인해줘."

브랜치 `design/lines-and-login`(바탕 `feat/community-chat` `a1937ee`), worktree `~/juby-fe-community`. 푸시하지 않았다.

## 1. 나란한 열의 선

### 찾은 방법

화면마다 모든 요소의 위·아래 테두리를 모아, 옆 열(가로로 안 겹치고 사이 160px 안)에 있는 가로선끼리 높이 차이를 쟀다.
14화면 × 1920·1600·1440·1280·1101(두 열이 나란한 폭). 세로선도 같은 방법으로 쟀지만 단추 안쪽 여백·표 칸 경계뿐이라 고칠 것이 없었다.

### 고친 것

| 화면 | 어긋남(1920) | 고친 방법 |
|---|---|---|
| 홈 | 검색창 아래 끝 ↔ 사용설명서 먹 선 6px | 오른쪽 열이 왼쪽 세 줄(검색·대표 종목·현재 주가)을 subgrid로 나눠 쓴다. 사용설명서 제목 줄이 검색 줄 높이를 채운다 |
| 홈 | 대표 종목 세 칸 아래 선 ↔ 4단계 아래 선 1px | 같은 줄에 놓고, 낮은 쪽이 늘어 아래 선이 줄 끝에 닿는다(세 칸 또는 네 단계가 고르게 늘어난다) |
| 홈 | 현재 주가 보기 ↔ 커뮤니티 먹 선 3px(사용자 캡처) | 같은 줄에 놓고 두 제목 줄을 46px·같은 제목 자리로 맞췄다(전엔 44px 바닥선 정렬 vs 46px 가운데 정렬) |
| 백테스트 | 화면 제목 ↔ 가이드 제목 먹 선 22px | 가이드 제목을 한 줄("JUBY의 백테스트 가이드")로, 화면 제목과 같은 높이로 선을 긋는다 |
| 백테스트 | 가이드 묶음 사이 선 ↔ 왼쪽 입력칸 테두리 5~6px(1280 이하), 고른 전략 카드 안 줄 ↔ 기간 칸 2px | 가이드 묶음 사이를 선 대신 여백으로 나눴다. 왼쪽 입력도 여백으로만 나뉜다 |
| 마이페이지 한눈에 보기 | 왼쪽 메뉴 맨 아래 선 ↔ 첫 두 칸 먹 선 5.5px | 메뉴 한 줄을 40px로 정하고(`--mypage-menu-row`), 내 정보 줄이 남는 높이를 채워 첫 먹 선이 메뉴 맨 아래 선에 온다 |
| 사용설명서 | 본문 첫 묶음 아래 선 ↔ 1단계 아래 선 1.2px(1280 이하) | 본문 묶음 사이를 선 대신 여백으로 나눴다(본문은 사용자가 채울 글이라 길이가 바뀌면 선 자리도 바뀐다) |

글 길이에 따라 선 자리가 움직이는 열은 픽셀을 맞춰도 다른 폭에서 다시 어긋난다. 그래서 그런 열(백테스트 가이드, 사용설명서 본문)은 선을 걷었다.
입력칸·단추·카드처럼 상자 테두리끼리 가까운 것은 열마다 제 리듬이라 맞추지 않았다.

### 판정 `judge/lines.mjs`

바꾸기 전 빌드에서 **10개 실패**(A1~A5 전부, G의 홈·비로그인 홈·백테스트·사용설명서·마이페이지)를 먼저 봤다.

| 항목 | 보는 것 |
|---|---|
| A1~A3 | 홈 세 쌍이 다섯 폭 모두 같은 높이(아래 끝 0.6px 안) |
| A4 | 백테스트 두 먹 선 |
| A5 | 마이페이지 메뉴 맨 아래 선 = 내 투자성향·관심종목 먹 선 |
| G | 두 열 화면 12개 × 다섯 폭: 옆 열 가로선 0.75~8px 어긋남, 먹 선끼리 24px 안 어긋남이 0. 단추·링크·입력칸·표 칸과 단추 안의 선은 뺀다 |

## 2. 로그인 화면

### 무엇이 별로였나

아이콘만 있는 동그라미 셋이 오른쪽 큰 회색 면 가운데 떠 있었다 — 무슨 단추인지 글자가 없고, 면이 비어 보였다.
왼쪽 "초보자를 위한 주식 비서, JUBY의 세계로!"는 무엇을 하는 화면인지 말하지 않았다. 1080 높이에서 아래 절반이 비었다.
그 전 판(가운데 흰 판)은 넓은 화면에서 좌우가 비었고, 2차 재정비 브랜치는 그 판으로 되돌렸다(사용자가 두 열보다 낫다고 했다).

### 방향(ui 스킬 `frontend-design`의 순서대로 — 계획, 계획 검토, 만들기, 캡처로 고치기)

- 대상: 주식을 처음 하는 사람. 이 화면의 일은 **쓰던 소셜 계정 하나를 한 번 눌러 들어오게 하는 것**과 **다른 계정으로 들어와 새 계정을 만드는 실수를 막는 것**.
- 색: 새 색 없이 토큰만(흰 바탕, 먹, 보조 먹, 옅은 면). 카카오 노랑과 네이버 초록 N은 회사 지침.
- 배치: 한 가지 일만 하는 화면이라 가운데 한 줄(400px). 다른 화면과 같은 제목 + 굵은 먹 선을 그 줄에 둔다.
  넓은 화면에서 가운데만 떠 보이지 않게 아래 "로그인하면 이렇게 시작해요" 세 칸이 폭을 받치고, 가운데 칸 폭이 단추 줄과 같아 칸 사이 선이 단추 양 끝과 한 줄이다.
- 검토에서 버린 것: 큰 JUBY 로고(머리글과 겹친다), 네이버 초록 단추에 흰 글자(대비 2.4:1), 왼쪽 홍보 글 | 오른쪽 로그인 두 열(지난번에 사용자가 싫어한 틀).

### 바뀐 것

| 전 | 후 |
|---|---|
| 아이콘만 있는 동그라미 셋(네이버·카카오·구글) | 글자가 든 48px 단추 셋: 카카오로 로그인(노랑) · 네이버로 로그인 · Google로 로그인(흰 바탕 + 먹 테두리 + 회사 아이콘) |
| 오른쪽 큰 회색 면 | 면 없음. 가운데 한 줄 |
| "초보자를 위한 주식 비서, JUBY의 세계로!" + 체크 세 줄 | "따로 가입할 필요 없이, 쓰던 계정으로 바로 시작해요." + 아래 순서 세 칸(투자성향 테스트 → 주식 백테스트 → AI 주가분석, 넓은 글꼴 번호) |
| 실패: "로그인에 실패했습니다. 다시 시도해주세요." | "로그인을 마치지 못했어요. 쓰려던 계정의 단추를 다시 눌러 주세요."(옅은 면) |
| — | 지난번에 로그인한 곳에 "최근 사용" 표시. 소셜 계정마다 JUBY 계정이 따로라 다른 곳으로 들어오면 새 계정이 생긴다 — 그 안내도 단추 아래에 적는다 |
| — | `?next=`로 왔으면 "로그인하면 보던 화면으로 돌아가요." |

- "최근 사용"은 누른 단추가 아니라 **로그인을 마친 콜백이 서버가 준 가입 경로**(`GET /api/members/me`의 `socialType`)로 적는다(`utils/lastLogin.ts`, localStorage `lastLoginProvider`).
  콜백은 원래 그 요청으로 온보딩 여부를 물었다 — **요청 수는 그대로 1건**이다(`needsOnboarding` → `checkAfterLogin`).
- 네이버 아이콘 파일(`public/social/naver.svg`)을 흰 N에서 초록 N으로 바꿨다. 마이페이지 "네이버로 가입한 계정"도 같은 파일을 흰 바탕에 그려 **아이콘이 안 보였다**(같이 고쳐짐).
- 카카오 단추 마우스·누름 색 토큰 `--color-kakao-hover`·`--color-kakao-active`를 더했다.

### 판정 `judge/login.mjs`

바꾸기 전 빌드에서 **8개 실패**를 먼저 봤다(L2는 처음에 단추 0개로도 통과해 "단추 셋"을 조건에 더했다).

| 항목 | 보는 것 |
|---|---|
| L1 | 1920·1440·1101: 단추 이름 셋이 순서대로, 48px, 제목 줄과 같은 폭, 화면 가운데 |
| L2 | 제목 "로그인" + 2px 먹 선, 단추 뒤 회색 면 0, 그림자 0, 글자 대비 4.5:1 이상(13.9·17.7·17.7) |
| L3 | "로그인하면 이렇게 시작해요" 세 칸, 가운데 칸 양 끝 = 단추 양 끝 |
| L4 | 단추마다 `/oauth2/authorization/{kakao,naver,google}`로 떠나고 `?next=`를 적어 둔다(그 이동은 204로 받아 백엔드로 안 나간다) |
| L5 | 기록이 네이버면 네이버 단추에만 "최근 사용", 읽어 주는 이름에도 들어간다. 기록이 없으면 없다 |
| L6 | 콜백이 서버 가입 경로(GOOGLE)를 적고, 회원 정보 요청은 1건 |
| L7 | 실패로 돌아오면 안내(무엇이·어떻게), `?next=`가 있을 때만 "보던 화면으로 돌아가요" |
| L8 | 375·320·768: 넘침 0, 단추가 본문 폭을 채우고 48px, 세 칸이 위아래로, 키보드 포커스 테두리 |
| L9 | 네이버 아이콘이 초록 |

## 남은 것
