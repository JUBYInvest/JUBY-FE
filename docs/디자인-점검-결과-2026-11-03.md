# 전 화면 디자인 점검 결과 (2026-11-03)

사용자 요청: "이 프로젝트의 전체적인 화면에서 디자인적으로 어색한 부분이나, 위계가 통일되어 있지 않거나, 세부항목별 어색한 부분을 찾아서 고쳐줘."

바탕은 팀 main `b66475c`(사용설명서 배포본), 브랜치 `design/consistency`.

## 어떻게 찾았나

화면 21가지(홈·상세·모아보기·백테스트 결과/빈 화면·AI·사용설명서 두 장·마이페이지 셋·투자성향 테스트/결과·로그인·없는 주소·로그인 실패,
그리고 비로그인 넷)를 1440px·390px에서 전체 캡처하고, 같은 탭에서 `main` 안의 제목(h1~h4)·단추·글자 크기·2px 선을 모두 뽑아 화면끼리 견줬다
(가짜 API — `judge/mock.mjs`. 실제 백엔드로 나간 요청 0건). 기준은 CLAUDE.md "잔가지"의 10-30 재정비 규칙과 11-03 구역 머리 규격
(`components/section.module.css`)이다.

## 찾은 것과 고친 것

위계를 세 단계로 맞췄다: **화면 제목 28px(900px 이하 24px) + 굵은 먹 선 > 구역 제목 20px(46px 줄 + 굵은 먹 선) > 칸 안 작은 제목 16~18px(가는 선·여백)**.

그대로 둔 것:

- **종목 상세의 16px 칸 머리**(시세 요약·기간별 주가 변화·뉴스 모아보기). 머리(이름·가격) 아래 먹 선 하나에 세 칸 머리(16px + 가는 선)가 같은 높이로 서는
  판이라(1600px 이상 세 열) 구역 제목 20px로 올리면 세 칸의 줄이 어긋난다. 1600px 아래에서 뉴스가 차트 아래로 내려와 먹 선을 하나 더 이는 것도 같은 까닭으로 둔다.
- 화면 제목의 "이용하기"(주식 백테스트 이용하기·AI 주가분석 이용하기)와 메뉴 이름의 차이. 글을 바꾸는 일이라 사용자가 정할 것으로 남긴다.
- 마이페이지 '점수를 매길 때 보는 비중' 막대(먹색)와 백테스트 비중 막대(초록)의 색 차이 — 앞은 성향의 설정값, 뒤는 점수라 뜻이 달라 둔다.
