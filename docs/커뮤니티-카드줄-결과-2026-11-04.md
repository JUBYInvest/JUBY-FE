## 요청

> 현재 커뮤니티는 전체, 종목 이렇게 되어있어. 2번사진을 최대한 참고하여 현재 왼쪽에 있는 전체/각 종목 선택창을 맨 위에 올려주고,

# 2부 — 글 구조(제목·본문·사진), 글쓰기 화면, 글 상세, 글 머리 등락률

## 요청

> 테스팅 완료 후 다음 사진처럼 커뮤니티 글쓰기 개념으로 생각해서 프로그래밍이 되었는지 확인해줘

사진은 토스증권 앱 커뮤니티 **인기** 탭(이번 주 인기글 · 실시간 인기 종목, 글마다 종목 로고·이름·등락률 → 굵은 제목 → 본문 두 줄 + 사진 → 공감·댓글·시각·⋯, 떠 있는 "글쓰기").

## 확인한 것(1부 커밋 4629ffa 기준) — 글쓰기 개념이 아니었다

| 사진 | 4629ffa |
| --- | --- |
| 글 = 굵은 **제목** + 본문(두 줄에서 자름) | 본문 한 칸, 전부 보임 |
| **사진** 첨부 | 없음(글 모양에 사진 칸이 없다) |
| 종목 줄에 **그날 등락률** | 본문 앞 종목 이름(초록 링크)뿐 |
| 떠 있는 **글쓰기 단추 → 글쓰기 화면** | 목록 위 한 줄 입력칸(줄바꿈 불가, 종목 = 고른 카드), 목업이라 잠김 |
| 인기 탭 안 이번 주 인기글 / 실시간 인기 종목 | 인기 = 전체 글 공감 순 |
| 글을 누르면 **글 상세**(댓글) | 글 상세 없음 |

서버에 건넨 글 모양 제안(`docs/커뮤니티-웹소켓-제안.md`)에도 제목·사진이 없었다. 차이를 알리고 범위를 물었다 — 사용자 답: **글 머리 등락률, 제목+본문 글과 글쓰기 화면, 글 상세**
(인기 탭 안 두 갈래는 고르지 않음), 올리기는 "아직 안 올림".
