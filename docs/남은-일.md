# 남은 일

코드로 확인했지만 아직 고치지 않은 것과, 사용자가 정하기 전에는 손대지 않는 것.
**코드를 고치기 전에 먼저 본다.** 고친 항목은 지우고, 새로 찾은 문제는 여기에 적는다.
ID(B-6, H-4 …)는 [테스트-결과-2026-09-23.md](테스트-결과-2026-09-23.md)의 항목 번호다.

## 고치지 않은 것

1. **`textOr()`가 대체표를 무조건 읽는다 — `8e21419`에서 생긴 회귀.** `MypagePersonalityPage`와
   `api/personality.ts`의 `submitTest`가 `textOr(값, fallback.description)`처럼 부르는데, 함수 인자는 호출
   전에 계산되므로 서버가 `PERSONALITY_INFO`에 없는 성향 이름을 주면 설명이 멀쩡해도
   `undefined.description`에서 던진다. 마이페이지는 구역 경계가 받아내고, 저장 흐름은 서버가 저장했는데
   "저장하지 못했어요"가 뜬다. 예전 `a || b`는 앞이 참이면 뒤를 읽지 않았다. 백엔드 성향은 enum 다섯 개라
   당장 닿을 가능성은 낮다. 실행으로는 확인하지 않았다. 고칠 때는 대체표 조회가 없을 수 있음을 막는다.
2. 검사에서 실패였는데 수정 지시서에서 빠진 것: **S-3**(종목 상세 실패 안내가 왼쪽 위 한 줄로만 뜬다),
   **W-API-6**(프론트 타입은 응답 필드를 거의 전부 필수·null 불가로 선언했는데 스웨거엔 필수 표시가 없다 —
   화면이 죽는 경로는 가드로 막았지만 타입과 실제는 여전히 어긋난다).
3. **로그인 상태의 수정은 실제 서버로 확인된 적이 없다**(성향 404, 저장 실패·다시 저장, 토큰 규칙, 관심종목).
   백엔드 OAuth 리다이렉트가 붙으면 이 흐름부터 실제로 돌려 본다.
4. 그 밖에 찾았지만 고치지 않은 것:
   - 백테스트 비교가 동점이면 번호 작은 성향을 "가장 잘 맞는"으로 단정하고, 비교 5건이 모두 서버 오류여도
     "아직 계산되지 않아"라고 말한다.
   - AI·백테스트는 성향 조회 500도 "성향 없음"으로 보인다(`.catch(() => null)`).
   - 백테스트의 기간 옵션·종목 목록을 못 받으면 프론트 값으로 조용히 바꾼다.
   - 종목명이 빈 문자열이면 탭 제목이 "JUBY"만 남는다.
   - `HomePage.module.css`의 `.asOf` 위 주석("지난 장 값을 보여주는 중")이 지금 동작과 맞지 않는다.
   - 백테스트에서 전략을 바꿀 때 고른 기간이 남는지는 프론트 표(`supportedPeriods`)로만 본다. 서버 기간
     목록이 프론트 표보다 좁아지면 선택칸은 "투자기간을 선택해주세요"로 보이는데 값은 남아 버튼이 켜진다.
     지금은 서버 목록과 프론트 표가 같아 드러나지 않는다(2026-09-26 실제 `/preset/options`로 확인).
   - AI 화면에 있는 동안 다른 탭에서 로그아웃하면 받아 둔 성향 문구가 그대로 남는다.
5. **파이어폭스는 확인한 적이 없다.** 크롬과 사파리(Playwright WebKit)만 돌렸다.

## 결정이 먼저 필요한 것

사용자가 정하기 전에는 구현하지 않는다.

- **성향→전략 자동 선택(B-6)**: 이 브랜치의 `dae25f3`이 로그인 시 성향에 맞는 전략을 미리 고르고 결과 문장이
  "나는 위험중립형, 여기에 맞는 …"을 말한다(`BacktestPage`의 추천 effect). 그걸 뺀 `0cf23ba`는
  `feat/backtest-strategy-cards`에만 있어 두 브랜치가 반대 결정을 들고 있다. 합치기 전에 방침을 정한다.
- **백테스트 중복 요청(B-3)**: 한 번 누르면 preset 6건이고, 고른 전략이 비교용 5건과 겹쳐 같은 요청이 두 번 나간다.
  B-6과 엮여 있다.
- **홈 카드 재요청**: 홈에 올 때마다 카드 3건(증권사 3회)이 다시 나간다. 캐시 기간을 정해야 한다.
- **종목 상세·뉴스 응답 캐시**: 같은 종목을 다시 열 때 기다리지 않게 하려면 캐시 기간을 정해야 한다.
  상세의 현재가는 실시간이고, 뉴스는 백엔드가 매달 1일에 새로 넣는다.
- **홈 시세표 첫 열 머리글 `번호`(H-4)**: 값은 종목코드다. 일부러 둔 표기라 사용자가 정할 때까지 둔다.
- **범위 밖 성향 점수(W-FN-1)**: 합이 10~90을 벗어나면 서버는 예외를 던지는데 `scoreToPersonality`
  (`utils/personality.ts`)는 결과를 낸다(9→안정형, 91·NaN→공격투자형). 실제 10문항으로는 범위 밖이 나오지
  않고 NaN은 보기가 빈 문항에서만 생긴다.
- **`nanoid` 취약점(W-B-4)**: vite → postcss 경로의 high 1건. 개발 의존성이라 번들엔 없다. 고치려면
  `package.json`을 건드려야 한다.
- Vercel이 `http://` 외부 주소로의 rewrite를 허용하는지는 실제 배포 전에는 확인할 수 없다(로컬 흉내로는 통과).
  같은 중계가 오래 걸리는 AI 답을 어디까지 기다리는지도 배포에서 본다 — 프론트는 제한 없이 기다린다.
- 검증 스크립트를 저장소에 둘지(CLAUDE.md "브라우저로 검증하는 법").
- **휴대폰 홈 시세표에서 거래대금 순으로 되돌아가기**: 600px 이하에서는 거래대금 머리가 숨어, 다른 정렬로 바꾼 뒤
  거래대금 순으로 돌아갈 방법이 새로고침뿐이다. 2026-09-26에 정렬 기준을 글로만 알리기로 정했다(선택칸은 두지 않음).
