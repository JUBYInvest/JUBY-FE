# 홈 커뮤니티를 채팅 모양으로 (2026-11-02)

사용자 요청: "커뮤니티가 글 형식이 아니라 채팅 형식이었으면 좋겠어."
브랜치 `feat/community-chat`(바탕 `refactor/cleanup` `c996d1b`), worktree `~/juby-fe-community`.

## 바탕 사정

- 커뮤니티는 홈 오른쪽 열 아래 칸 하나뿐이고, 백엔드가 없어 지어낸 예시 글 다섯 줄을 "예시"라고 밝혀 보였다(2026-10-30 사용자 결정).
- 백엔드에 커뮤니티·채팅 API는 여전히 없다. JUBY-BE 기본 줄기 `dev`(`b1aedd7`, 2026-10-29)의 컨트롤러 13개를 GitHub에서 읽어 확인했다(읽기만).
  `feature/websocket/#73`(2026-08)은 증권사 실시간 시세용 웹소켓이라 채팅과 무관하다.
- 그래서 이번 일은 **예시 데이터 그대로 모양만 채팅으로 바꾸는 것**이다. 실제로 말을 주고받으려면 백엔드가 먼저다(`남은-일.md` 7번).

## 바꾼 것

| 전 (게시판) | 후 (채팅) |
|---|---|
| 글 다섯 줄: 말머리(종목·자유·질문) + 제목 + 글쓴이·몇 분 전·댓글 수·좋아요 수 | 말 아홉 개가 오가는 대화: 동그란 첫 글자 + 이름·시각 + 말풍선 |
| 인기·최신 정렬 탭 | 없음. 채팅은 시간 순(오래된 말이 위, 최신이 아래) |
| 글마다 "예시 글" | 칸 제목 옆 "예시", 잠긴 입력칸 "채팅은 준비 중이에요", 칸 아래 "지금 보이는 대화는 예시예요" |
| 글이 칸 높이만큼 늘어남 | 높이 360px(600px 이하 320px) 대화창 안에서만 스크롤, 처음엔 최신 말이 보인다 |
| — | 입력칸 + 보내기(둘 다 잠김). 백엔드가 없어 써도 갈 곳이 없다 |

- 예시 대화(`src/content/communityPreview.ts`)는 서로 묻고 답하는 흐름으로 다시 지었다. 전처럼 투자를 권하거나 수익을 말하지 않고,
  질문·감상·서비스 쓰는 법만 담았다(MDD 뜻을 묻고 답하기 등). 종목 이름이 붙은 말은 말풍선 앞에 초록 글자로 종목을 적는다.
- 같은 사람이 이어 말하면 이름·시각을 한 번만 보이고, 화면 읽기 프로그램에는 이름을 남긴다.
- 시각은 처음 그릴 때의 지금에서 "몇 분 전"을 빼 한국 시각 "오전 10:56"으로 적는다(`utils/date toKoreanClock`, 단위 판정 1개 추가).
- 대화창은 `column-reverse`로 세워 스크롤 기준이 아래 끝이다. 스크립트로 내리지 않아도 처음부터 최신 말이 보이고, 글꼴이 늦게 와 높이가 바뀌어도
  아래에 붙어 있다. 말 순서(DOM)는 오래된 순 그대로라 읽어 주는 순서도 같다. 창은 `role="log"`이고 Tab으로 들어가 키보드로 스크롤한다.
- 디자인 규칙대로 테두리는 스크롤되는 대화창에만, 말풍선은 옅은 면, 등락색(빨강·파랑)은 쓰지 않는다. 보내기는 primary 단추(잠김)다.
- 요청은 늘지 않았다. 커뮤니티 칸은 서버를 부르지 않는다(공통 판정 7번의 화면별 요청 순서가 그대로다).

## 판정

새 판정 `judge/community.mjs`(9항목)를 먼저 쓰고 **바꾸기 전 빌드에서 7개가 실패하는 것**을 본 뒤 만들었다(대화창 0개·정렬 탭 1개 등).

| 항목 | 보는 것 |
|---|---|
| C1 | 대화창 하나, 말 9개, 댓글·좋아요 수 없음, 정렬 탭 없음 |
| C2 | 1920×1080: 창 안에서 스크롤하고 처음엔 마지막 말이 다 보이며 첫 말은 가려져 있다. 페이지는 움직이지 않는다 |
| C3 | 시각이 오래된 순이고 처음 "오전 9:56"·마지막 "오전 10:56"(시계를 목 11:00에 못박음) |
| C4 | 보이는 이름 8개(이어 말한 말은 이름 생략), 그 말도 이름을 읽어 준다 |
| C5 | 입력칸·보내기 잠김, 안내 "준비 중", 입력칸 16px, 눌러도 요청 0건·말 수 그대로 |
| C6 | 창이 Tab으로 들어가지고(`tabindex=0`) Home으로 첫 말까지 올라간다 |
| C7 | 등락색 칠한 요소 0, 말풍선 9개 모두 옅은 면 |
| C8 | 1440·1100·375·320: 가로 넘침 없음, 말풍선이 창 밖으로 안 나감, 보내기 단추가 화면 안·높이 40px 이상 |
| C9 | 비로그인도 같은 대화·잠긴 입력칸, 커뮤니티·채팅 요청 0건 |

기존 판정 중 옛 모양을 전제로 적힌 두 항목을 새 모양에 맞췄다(`feature.mjs`).

- H-1(1920×1080 첫 화면): "커뮤니티 글 5개" → "커뮤니티 대화창·입력칸이 첫 화면에 다 들어온다".
- H-4(예시 표시): "'예시 글' 5개" → "칸 제목 옆 '예시' + 칸 아래 안내". 대화가 `src/content/communityPreview.ts`에만 있는지는 그대로 본다.
