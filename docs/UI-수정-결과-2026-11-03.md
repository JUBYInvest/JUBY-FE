### 4. −3.06%와 −3.73%의 기준

**결론: 기준이 다르다. −3.06%는 KIS가 준 `prdy_ctrt`를 그대로 옮긴 값이고 기준은 실전 약 229,000원이다. −3.73%는 백엔드가 DB의 두 날 종가로 계산한 값이고 기준은 모의 228,000원이다. 프론트는 둘 다 계산하지 않는다.**

- 홈 −3.73%: `StockService.java:76`(baseDate 바로 앞의 DB 날짜) → `:81-87`(그날 종가 맵) → `:99` `calculateFluctuation`. 계산식은 `round((종가−전일종가)/전일종가×10000)/100`이다(`…/stock/converter/StockConverter.java:96-104`). 두 값 모두 DB, 곧 모의 도메인 값이다.
- 역산(등락률이 소수 둘째 자리에서 반올림됐으므로 ±0.005%p 폭을 넣었다):

| | 계산 | 결과 | 반올림 폭 안의 범위 | 전일 종가(호가 500원 단위) |
|---|---|---|---|---|
| 상세 | 222,000 / (1 − 0.0306) | 229,007.6 | 228,996 ~ 229,019 | **229,000** |
| 홈 | 219,500 / (1 − 0.0373) | 228,004.6 | 227,993 ~ 228,016 | **228,000** |

  검산: (222,000 − 229,000) / 229,000 = −3.057% → −3.06%. (219,500 − 228,000) / 228,000 = −3.728% → −3.73%.
- 즉 11월 2일 종가부터 실전 229,000, 모의 228,000으로 1,000원 차이가 난다.
- 맞지 않는 점이 하나 있다. `docs/남은-일.md:185`와 `docs/검토-결과-2026-11-02.md:121`은 "같은 밤" 실전 현재가를 230,000원으로 적었다.

  - 그 관측이 11/2 새벽, 그러니까 10/30 종가를 본 것이었을 수 있다(**추정**).
  - 기준가를 정확히 보려면 KIS `prdy_vrss`가 든 **실제 응답이 필요함.** 백엔드는 상세 응답을 만들 때 `prdy_vrss`를 버린다.
