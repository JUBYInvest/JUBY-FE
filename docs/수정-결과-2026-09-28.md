### 비고

- **G-10 재현 경로.** 검색창은 홈에만 있다. 지시서 경로(A에서 다시 시도 → 홈 → 검색으로 B → 뒤로 두 번 → A)는 홈을 거치며 상세 화면이
  새로 마운트돼 `retryCount`가 0으로 돌아간다. 그래서 고치기 전에도 A 요청이 더 나가지 않았다(재현 안 됨). 같은 상세 화면이 살아 있는 채
  종목만 바뀌는 경우(F-11 판정과 같은 `pushState` + `popstate`로 B → `history.back()`)에서 A 요청이 3 → 4로 재현돼 그 경로로 고치고 쟀다.
  지금 화면에는 상세에서 다른 상세로 바로 가는 링크가 없어 사용자가 닿기는 어렵다. 두 경로 모두 끝 회귀에 넣었다.
- **G-1 덧붙임(StrictMode)**은 방향과 다르지 않고 더한 것이다. 운영 빌드는 StrictMode가 아니라 effect가 한 번만 돌아 이 가드가 닿지 않는다. 가드가 막는 것은 개발 서버에서만 쟀다(위 표).
- **G-4 판정식**은 지시서 기대를 바꾸지 않았다 — 넣는 방법만 바꿨다(위 표).
