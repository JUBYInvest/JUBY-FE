## 1. 백엔드 연결

운영 스웨거(`GET /v3/api-docs`)와 JUBY-BE dev(`0914299`, 읽기만)로 확인했다.

- **투자성향 `GET·POST /api/personality-tests`는 바뀌지 않았다.** 백엔드 코드는 7월 이후 그대로이고, 명세 모양(문항·보기·점수, `scores` 배열)이 프론트와 같다.
  사용자가 "다른 API일 수도 있음"이라고 해 명세 전체를 프론트가 쓰는 경로와 견줬다. 새로 생기거나 바뀐 것은 아래다.
- 새 API: `GET /api/market-indices`(지수), SSE `GET /api/stream/prices`(전 종목·지수 실시간), `GET /api/stream/prices/{code}`(종목 하나).
- 바뀐 응답: `/api/stocks`에 `asOf`·행마다 `realtime`, 관심종목 행·상세에 `realtime`.

붙인 것:

- 지수 띠: 예시 값("(목업본)")을 걷고 실제 API. 장중에는 실시간 값과 "실시간". 포인트 대비는 API에 없어 대비율만 적는다.
- 실시간 시세(`src/api/realtime.ts`): 연결 하나를 앱 전체가 같이 쓴다. 홈 시세표·대표 종목 카드·관심종목·종목 상세 머리 가격·커뮤니티 등락률에 덮는다.
  줄 순서는 받거나 정렬할 때만 정한다(값이 1초마다 바뀌어도 줄이 움직이지 않는다). 종목 하나 스트림은 쓰지 않는다 — 전 종목 연결에 그 종목이 들어 있다.
- 가격 옆 기준 글은 `utils/priceBasis.ts` 하나로: "실시간" / "○월 ○일 HH:MM 기준" / "○월 ○일 종가 기준".

**백엔드에 부탁할 것**: `SecurityConfig`의 공개 목록(`allowUris`)에 `/api/stream/**`와 `/api/market-indices`가 없어 비로그인은 401이다
(스트림 DTO 주석은 "인증 없이 열리는 공개 경로"라고 적고 있다). 지금 비로그인 화면에는 지수 띠와 실시간 값이 없다. 공개로 열면 프론트는 고칠 것 없이 붙는다.

## 2. UI/UX

- 휴대폰 홈(1100px 이하): 검색 → 대표 종목 → 시세표(10행 + "종목 더 보기") → 처음 시작하기 → 커뮤니티. DOM도 같은 순서. 휴대폰은 마친 시작 단계를 접는다.
- 백테스트: 왼쪽 진행 단계 줄을 걷고 전략 카드를 그 자리로. 가운데 전략 목록 상자를 없애 전략을 고르는 곳이 하나다. 좁은 화면은 카드가 입력 ②칸에 선다.
  "다시 테스트" → "성향 다시 검사".
- AI 첫 화면: 워터마크 대신 성향 한 줄("지금 투자성향은 ○○이에요")과 문답 예시 넷(사용설명서 4장 사례). 누르면 입력칸에 채운다. 첫 예시의 답은 내 성향으로 적는다.
  로그인 안내 모달도 '해요'체("로그인하면 쓸 수 있는 기능이에요").
- 작은 글자: 12·13·14·16px 네 단계, 굵기 400·600·700. 11px(→12), 15px(화면 글자 →14, 읽는 글 →16), 굵기 500을 없앴다.

## 3. 프론트엔드

- CI(`.github/workflows/ci.yml`): 타입·린트·빌드·단위 판정, 그 뒤 운영 빌드를 띄워 flow·repro·ai·market. 픽셀을 재는 묶음은 리눅스 글꼴에서 흔들릴 수 있어 넣지 않았다.
  **첫 푸시 전에는 GitHub에서 돌려 보지 못했다.**
- CLAUDE.md: 1,208줄(175KB) → 277줄(34KB). 날짜·결정 이야기를 걷고 지금 규칙만 남겼다.
- 소스 주석: 178개 파일에서 날짜·"사용자" 인용·지시서 번호·커밋 해시·"예전엔" 이야기를 걷었다(이유는 지금 시제로 남김). 주석만 바뀌었는지
  TypeScript 출력으로 견줬다 — 121개 파일 코드 변화 없음.
- 튼튼한 레이아웃: 마이페이지 휴대폰 메뉴의 글자 폭 산수를 걷고 공용 밑줄 탭을 그대로 쓴다(좁으면 탭 줄만 옆으로 민다). 지수 띠 높이를 변수로(띠가 없으면 0).
- 같은 값 줄이기: 로그인 모달 하나(`LoginModal`), 줄 전체 링크(`a11y rowLink`), 안내 글(`section note`), 마이페이지 넓은 메뉴(`sideList`), 안 쓰는 CSS.
- 데이터 한 번에: 실시간은 연결 하나, REST는 `api/memo.ts shared` — 시세표·관심종목·성향·회원 정보를 화면끼리 1분 같이 쓴다(쓰기 뒤 지운다).
